MH

Sistema IoT de Monitoramento de Nível de Rios

Protótipo acadêmico para coleta, visualização e alerta de níveis hídricos com foco em prevenção de enchentes.

Objetivos

Fornecer uma plataforma de visualização em tempo real que permita autoridades e gestores monitorarem níveis de água, detectarem tendências de risco e acionarem medidas preventivas com antecedência.

  • Detecção e notificação de riscos (normal / alerta / emergência).
  • Visualização geográfica dos pontos monitorados (mapa interativo).
  • Geração de relatórios e histórico para análises hidrológicas.

Escopo do Protótipo

  • Interface web responsiva (dashboard, sensores, mapa, alertas, relatórios e página institucional).
  • Simulação de dados para prototipagem; possibilidade de integrar com Arduino/ESP32 e backend real.
  • Camada meteorológica (radar) disponível via RainViewer para contexto pluviométrico.

Como contribuir

O protótipo foi pensado para facilitar contribuições de alunos e desenvolvedores:

  • Substituir dados simulados por uma API REST ou WebSocket.
  • Adicionar autenticação e controle de permissões.
  • Integrar fontes SIG/WMS locais para camadas de rios e bacias.

Tecnologias

  • Frontend: HTML, CSS e JS puros (sem frameworks)
  • Mapas: Leaflet + OpenStreetMap
  • Camadas meteorológicas: RainViewer (tiles de radar)
  • Backend (sugestão): Python / FastAPI ou Node.js — banco: PostgreSQL
